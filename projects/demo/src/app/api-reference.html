API reference

Command

The shape every registered command has. Only label and execute are required.

CommandRegistryService

Injectable anywhere. Registering a duplicate id or colliding shortcut throws immediately, rather than silently overriding the earlier registration.

CmdkPaletteComponent

Selector ngx-cmdk-palette. Mount once in your root template — it reads live from CommandRegistryService, no extra wiring needed.

Icons

Command.icon and SearchResult.icon both render as an extra class on an empty <span class="cmdk-item-icon"> — ngx-cmdk ships no icon system, your stylesheet decides what it looks like. Leave icon unset and nothing renders.

provideCmdk()

Configures the palette's open shortcut app-wide. Call it once in app.config.ts.

Search providers

A second registration surface, alongside commands — attaches an async data source; typing fans out to every registered provider and merges the results. With zero providers registered, Commands keep fuzzy-matching as before.

Registered from whichever component owns the data, unregistered on destroy the same way a Command is:

Scoping a search

Type a provider's key followed by : (e.g. "fruits:"), or click its chip, to scope search to just that provider — remove with Backspace.

Recent searches

Opt-in and hard-gated — unset, nothing is tracked. Configured, every search-result selection (not Commands) is saved to localStorage and reappears above Commands next time the palette opens with an empty, unscoped query.

  • Hidden (not deleted) if its provider isn't currently registered — reappears once it re-registers.
  • Removed for real if resolve() fails or returns null.

Favourites & Settings

Opt-in and hard-gated like Recent Searches. A favourite is a plain {{ '{' }} label, path {{ '}' }} pair the end user types in themselves — persisted to localStorage, selected via a navigate callback you supply, so this library never imports @angular/router. Appears below Actions in the same browse view Recent Searches uses.

Press , with an empty, unscoped query to open Settings — favourites are added, removed, and reordered there, and a "Clear recent searches" action appears if that's configured.

Translatable labels

Every piece of UI text comes from CmdkLabels, optional and defaulting to English. Like the storage-key options, labels is a callback — read a locale signal inside it and text switches live, no remount required.

CmdkIssueService

Every error this library catches is logged (console.error/console.warn) and reported through this service, so you can build your own UI instead of the library imposing one.

Shortcut rules

  • mod is a platform alias — ⌘ on Mac, Ctrl on Windows/Linux — so you don't need to branch on platform.
  • Needs a real modifier (mod, ctrl, alt, or cmd/meta) plus exactly one letter (a-z), e.g. "mod+s". A bare key, shift-only combo, digit key, or non-letter key is rejected at registration — digits are reserved for favourites (mod+1 through mod+9).
  • A command's shortcut only fires while the palette is open. The one always-live shortcut, even when closed, is the configured open-shortcut itself.
  • Shortcut hints render with the correct symbol for your OS automatically.
