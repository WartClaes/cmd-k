API reference

Command

The shape every registered command has. Only label and execute are required.

CommandRegistryService

Injectable anywhere (providedIn: 'root'). Call register() from any component, directive, guard, or service — registration isn't confined to a single root location. It returns an unregister function; pass it to DestroyRef.onDestroy() for automatic cleanup. Registering a duplicate id or a colliding shortcut throws immediately, rather than silently overriding the earlier registration.

CmdkPaletteComponent

Selector ngx-cmdk-palette. Mount it once, typically in your root component's template. It reads live from CommandRegistryService, so it reflects whatever is currently registered with no extra wiring.

Icons

Both Command.icon and SearchResult.icon render the same way: as an extra CSS class on an otherwise-empty <span class="cmdk-item-icon">. ngx-cmdk ships no icon system of its own — your app's global stylesheet decides what that class actually looks like (an icon-font ::before glyph, a background-image, a masked SVG, whatever you already use), the same "bring your own styling" approach as the --cmdk-* custom properties elsewhere in this library. Leave icon unset and nothing extra renders.

provideCmdk()

Configures the palette's open shortcut app-wide. Call it once in app.config.ts.

Search providers

A second registration surface, alongside commands. Call SearchRegistryService.register() from anywhere to attach an async data source to the palette — typing fans the query out to every registered provider and merges the results into a single flat list. With zero providers registered, typing behaves exactly as it always has: Commands keep fuzzy-matching.

A provider that's still running when searchTimeoutMs (default 5000ms, configurable via provideCmdk()) elapses contributes no results for that query — it doesn't block the others. Typing is already debounced (200ms) before search() is ever called, so a provider doesn't need its own debounce logic.

Scoping a search

With one or more providers registered, typing a provider's key followed by : (e.g. "fruits:") converts it into a scope token — only that provider is queried until the token is removed with Backspace. The same scoping is also available by clicking a category chip below the search input.

Recent searches

Opt-in and fully hard-gated: with no recentSearchesStorageKey configured, nothing is tracked, persisted, or rendered — zero behavior change. Configure it and every search-result selection (not Commands) is remembered to localStorage under the key your callback returns, and reappears in a "Recent searches" section above Commands the next time the palette opens with an empty, unscoped query — even after a reload. The key is a plain callback, not a static string, so a host app can scope it per signed-in user (e.g. () => userId() ? 'myapp-recents-' + userId() : null) to avoid leaking one account's history to another on a shared device.

A result only becomes a persistable recent if its provider sets resultId; selecting a persisted recent from a previous session calls that provider's resolve(resultId) to reconstruct a fresh, live result (never called just to list recents — only when one is actually picked). If the provider that produced a recent isn't currently registered, that entry is hidden from the list but left untouched in storage — it reappears once the provider registers again. If resolve() fails or returns null, the entry is confirmed gone and removed for real.

Favourites & Settings

Opt-in and hard-gated like Recent Searches: with no favouritesStorageKey configured, Favourites track nothing and never render. A favourite is a plain {{ '{' }} label, path {{ '}' }} pair the end user types in themselves — not a registered Command — persisted to localStorage and selected via a navigate: (path) => void | Promise<void> callback you supply, so this library never imports @angular/router itself.

Favourites appear below Actions in the same empty-query, unscoped browse view Recent Searches uses. Each favourite's position assigns its shortcut — the 1st is mod+1, up to the 9th at mod+9 — which is why the list is capped at 9 and why Command shortcuts can no longer use a digit key at all, with or without a modifier: the digit namespace is reserved for favourites everywhere in this library.

Press , with an empty, unscoped query to open Settings — a second view inside the same palette, not a separate component to mount — where favourites are added, removed, and reordered, and where a "Clear recent searches" action lives if recentSearchesStorageKey is configured. Settings itself is reachable only when at least one of those two keys is set; with neither configured, , does nothing.

Translatable labels

Every piece of UI text the palette and Settings render — dialog and input aria-labels, group headings, footer hints, button labels, placeholders, and messages — comes from CmdkLabels. The labels option is optional and defaults entirely to English (DEFAULT_CMDK_LABELS); a partial override you provide is merged over those defaults, so any key you don't set keeps its English text.

Like favouritesStorageKey and recentSearchesStorageKey, labels is a callback rather than a static object — read a locale signal inside it and the palette's text switches live whenever that signal changes, no remount required. favouritesLimitReached is the one label containing a %max% token, which is substituted with the actual favourites cap before it's rendered.

CmdkIssueService

Every error this library catches on your behalf — a failing command, a failing or slow search provider, a failing search result — is logged via console.error/console.warn and also reported through this service, so you can build your own UI on top instead of the library imposing one.

Shortcut rules

  • mod is a platform alias — ⌘ on Mac, Ctrl on Windows/Linux — so you don't need to branch on platform.
  • Every shortcut needs a real modifier (mod, ctrl, alt, or cmd/ meta) plus exactly one key — a single letter (a-z), e.g. "mod+s" or "mod+shift+p". A bare key, a shift-only combo, a digit key, or a key that isn't a single letter is rejected at registration time — digits are reserved for favourite shortcuts (mod+1 through mod+9).
  • A command's shortcut only fires while the palette is open — press it, and that command runs immediately, the same as selecting it and pressing Enter. The one shortcut that's always live, even when the palette is closed, is the configured open-shortcut itself.
  • Shortcut hints render with the correct symbol for your OS — ⌘ on Mac, Ctrl elsewhere — automatically.
