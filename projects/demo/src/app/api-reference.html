API reference

Command

The shape every registered command has. Only label and execute are required.

CommandRegistryService

Injectable anywhere (providedIn: 'root'). register() returns an unregister function — pass it to DestroyRef.onDestroy() for cleanup. A duplicate id or colliding shortcut throws immediately rather than silently overriding the earlier registration.

CmdkPaletteComponent

Selector ngx-cmdk-palette. Mount it once, typically in your root component's template. It reads live from CommandRegistryService, so it reflects whatever is currently registered with no extra wiring.

Icons

Command.icon and SearchResult.icon both render as an extra class on an otherwise-empty <span class="cmdk-item-icon">. ngx-cmdk ships no icon system — your global stylesheet decides what that class looks like (icon-font, background-image, masked SVG, whatever you already use). Leave icon unset and nothing renders.

provideCmdk()

Configures the palette's open shortcut app-wide. Call it once in app.config.ts.

Search providers

A second registration surface, alongside commands. SearchRegistryService.register() attaches an async data source — typing fans the query out to every registered provider and merges the results into one flat list. With zero providers registered, Commands keep fuzzy-matching as before.

  • Typing is already debounced (200ms) before search() runs — no need for your own debounce.
  • A provider still running when searchTimeoutMs (default 5000ms) elapses contributes no results for that query, without blocking the others.

Registered from whichever component owns the data, typically in the constructor, and unregistered on destroy the same way a Command is:

Scoping a search

Type a provider's key followed by : (e.g. "fruits:"), or click its category chip below the search input, to scope the search to just that provider until the token is removed with Backspace.

Recent searches

Opt-in and hard-gated: with no recentSearchesStorageKey configured, nothing is tracked, persisted, or rendered. Configure it and every search-result selection (not Commands) is saved to localStorage under your callback's key, reappearing above Commands next time the palette opens with an empty, unscoped query.

The key is a callback, not a static string, so a host app can scope it per signed-in user (e.g. () => userId() ? 'myapp-recents-' + userId() : null) to avoid leaking one account's history to another on a shared device.

  • A result becomes a persistable recent only if its provider sets resultId.
  • Picking a recent from a previous session calls its provider's resolve(resultId) to reconstruct a fresh result — never called just to list recents.
  • If that provider isn't currently registered, the entry is hidden but kept in storage, reappearing once the provider registers again.
  • If resolve() fails or returns null, the entry is removed for real.

Favourites & Settings

Opt-in and hard-gated like Recent Searches: with no favouritesStorageKey configured, nothing tracks or renders. A favourite is a plain {{ '{' }} label, path {{ '}' }} pair the end user types in themselves — persisted to localStorage and selected via a navigate: (path) => void | Promise<void> callback you supply, so this library never imports @angular/router.

Favourites appear below Actions in the same browse view Recent Searches uses. Each one's position assigns its shortcut — mod+1 through mod+9 — which is why the list caps at 9, and why the digit namespace is reserved for favourites everywhere in this library, including Commands.

Press , with an empty, unscoped query to open Settings — a second view in the same palette — where favourites are added, removed, and reordered, and a "Clear recent searches" action lives if that's configured. Settings is reachable only when at least one storage key is set.

Translatable labels

Every piece of UI text the palette and Settings render comes from CmdkLabels, optional and defaulting entirely to English (DEFAULT_CMDK_LABELS). A partial override merges over those defaults, so any key you don't set keeps its English text.

Like the storage-key options, labels is a callback, not a static object — read a locale signal inside it and the palette's text switches live, no remount required. favouritesLimitReached is the one label with a %max% token, substituted with the actual favourites cap before it's rendered.

CmdkIssueService

Every error this library catches — a failing command, a failing or slow search provider, a failing search result — is logged via console.error/console.warn and reported through this service, so you can build your own UI on top instead of the library imposing one.

Shortcut rules

  • mod is a platform alias — ⌘ on Mac, Ctrl on Windows/Linux — so you don't need to branch on platform.
  • Needs a real modifier (mod, ctrl, alt, or cmd/meta) plus exactly one letter (a-z), e.g. "mod+s". A bare key, shift-only combo, digit key, or non-letter key is rejected at registration — digits are reserved for favourites (mod+1 through mod+9).
  • A command's shortcut only fires while the palette is open. The one always-live shortcut, even when closed, is the configured open-shortcut itself.
  • Shortcut hints render with the correct symbol for your OS automatically.
